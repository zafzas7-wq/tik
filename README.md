# 8–9 семинар: Python бағдарламалары

Бұл жоба ақпарат теориясы бойынша екі тақырыпты қамтиды.

## Семинар 8 — Хэмминг коды

`seminar8_hamming.py`:
- бақылау биттерінің санын есептеу: `2^r >= m + r + 1`;
- екілік ақпаратты Хэмминг кодымен кодтау (жұптық бақылау);
- синдром арқылы **бір биттік** қатені тауып, түзету;
- екі кодтық сөз арасындағы Хэмминг қашықтығын есептеу.

**Маңызды:** кәдімгі Хэмминг коды екі биттік қатені сенімді түзете алмайды. Бұл бағдарламаның декодері ең көбі бір бит бұзылды деп есептейді.

## Семинар 9 — Фано шарты, префикстік және постфикстік кодтар

`seminar9_fano.py`:
- префикстік код үшін Фано шартын тексеру;
- постфикстік код үшін кері Фано шартын тексеру;
- хабарламаны екілік кодқа айналдыру және қайта декодтау;
- символдардың жиіліктері бойынша орташа код ұзындығын есептеу;
- бірдей ұзындықтағы код үшін ең аз бит санын табу.

## Іске қосу

Python 3 орнатылған болса, терминалда орындаңыз:

```bash
python seminar8_hamming.py
python seminar9_fano.py
python -m unittest test_seminars.py -v
```

Windows жүйесінде `python` пәрмені жұмыс істемесе, `py` қолданыңыз.

Қосымша кітапханалар қажет емес.

## GitHub-қа жүктеу

1. GitHub-та жаңа ашық немесе жабық repository жасаңыз: `seminar-8-9-python`.
2. **Add file → Upload files** түймесін басыңыз.
3. `seminar8_hamming.py`, `seminar9_fano.py`, `test_seminars.py`, `README.md` файлдарын таңдаңыз.
4. **Commit changes** басыңыз.

Немесе Git орнатылған болса, жоба бумасында:

```bash
git init
git add .
git commit -m "Add seminar 8 and 9 Python code"
git branch -M main
git remote add origin https://github.com/USERNAME/seminar-8-9-python.git
git push -u origin main
```

`USERNAME` орнына GitHub пайдаланушы атыңызды жазыңыз. Репозиторийді GitHub-та алдын ала жасаңыз.
